# A Bigger Program

Here we will build a program up bit by bit, they way any develper would.

The spec is pretty loose, we will read some football match data from a file.

The match data isn't in the format we want, it is in `home_team away_team home_score away_score` i.e. `England USA 2 0`

We want to print them all out in the more familiar `home_team home_score V away_score away_team` ie. `England 2 V 0 USA`

We want to detect any errors in the data, but continue on if we can.

We want to output a league table
